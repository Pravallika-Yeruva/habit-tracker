# BrightSteps

BrightSteps is a habit tracker for planning tasks, reminders, and recurring routines.

## Development

```sh
npm ci
npm start
```

## Tests and build

```sh
npm test -- --watch=false
npm run build
```

Pushing to `main` builds the app and deploys it to GitHub Pages at
`https://pravallika-yeruva.github.io/habit-tracker/`.
